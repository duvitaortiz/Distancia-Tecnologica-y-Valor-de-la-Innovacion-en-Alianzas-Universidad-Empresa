# Distancia-Tecnologica-y-Valor-de-la-Innovacion-en-Alianzas-Universidad-Empresa
Repositorio de tesis sobre el efecto de la distancia tecnológica y la experticia de colaboradores en el valor de la innovación conjunta universidad-empresa. Incluye procesamiento de datos de patentes, cálculo de DeTech, modelos OLS/NB2, pruebas de robustez y visualizaciones en Python.
